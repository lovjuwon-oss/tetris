# 모바일 지원 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 테트리스를 휴대폰 세로 화면에서 터치(화면 버튼 + 보드 제스처)로 플레이할 수 있게 한다.

**Architecture:** 터치 입력은 `src/platform`의 새 모듈이 기존 `InputEvent`(press/release/focusLost)로 바꿔 core에 넘긴다. `src/core`는 수정하지 않는다. 제스처 판정(`gestures.ts`)과 칸 크기 계산(`layout.ts`)은 순수 로직으로 분리해 테스트하고, 배치는 CSS 그리드가 정하며 JS는 보드 빈칸의 실제 크기를 재서 칸 크기를 정한다.

**Tech Stack:** Vite, TypeScript(strict), Canvas 2D, Pointer Events, Vitest, ESLint, Prettier. Windows + Git Bash, Node 24. 외부 의존성 추가 없음.

**Spec:** `docs/superpowers/specs/2026-09-29-mobile-design.md` (게임 규칙은 `docs/superpowers/specs/2026-09-28-tetris-design.md`)

## Global Constraints

- `src/core`의 파일은 수정하지 않는다. 터치 입력도 기존 `InputEvent`, `Action` 타입(`src/core/game.ts`)만 쓴다.
- 모바일 배치 기준: 화면 폭 700px 이하. 터치 버튼은 `(pointer: coarse)`이면서 폭 700px 이하일 때만 보인다.
- 가로 방향 쿼리: `(pointer: coarse) and (orientation: landscape) and (max-height: 500px)`.
- 칸 크기: PC `max(12, ⌊창 높이 × 0.85 ÷ 20⌋)`, 모바일 `max(12, ⌊min((빈칸 폭 − 4) ÷ 10, (빈칸 높이 − 4) ÷ 20)⌋)`. 미리보기 칸은 PC 0.7배, 모바일 0.5배.
- 제스처 상수: TAP_MAX_MOVE_PX 10, TAP_MAX_MS 250, SOFT_DROP_DELAY_MS 120, HARD_DROP_MIN_SPEED 1.0 px/ms, HOLD_MIN_DISTANCE_PX 40, HOLD_MIN_SPEED 0.5 px/ms, VELOCITY_WINDOW_MS 80.
- 보드 제스처는 `pointerType`이 `touch` 또는 `pen`일 때만 처리한다. 화면 버튼과 오버레이 클릭은 마우스로도 동작한다.
- 모바일 버튼 높이 최소 56px, 오른쪽 열 폭 76px.
- `npm run check`(tsc + eslint + prettier --check + vitest --coverage)가 통과해야 작업 완료다. 커버리지 대상은 `src/core/**`, `src/platform/gestures.ts`, `src/platform/input-hub.ts`, `src/render/layout.ts`이고 라인 90% 이상.

## Review Focus

스펙이 암시하지만 기능 테스트만으로는 놓치기 쉬운 입력들이다. 각 줄의 테스트는 담당 Task에 들어 있다.

1. **칸 크기가 0일 때의 드래그** (레이아웃 전, 숨겨진 캔버스): 무한 루프나 이동 폭주 없이 아무것도 보내지 않아야 한다 → Task 3 `cellPx가 0이면 가로 드래그를 무시한다`.
2. **빈칸 크기가 0×0으로 측정될 때** (요소가 아직 배치되지 않음): 칸 크기가 NaN이나 음수가 아니라 최소값 12여야 한다 → Task 1 `빈칸이 0×0이면 최소 칸 크기`.
3. **down 없이 들어온 up/move** (오버레이에서 시작한 손가락이 오버레이가 사라진 뒤 캔버스에서 떨어짐): 무시해야 한다 → Task 3 `시작하지 않은 포인터의 move/up은 무시한다`.
4. **blur로 이미 해제된 버튼에 뒤늦게 오는 pointerup**: release가 두 번 나가지 않아야 한다 → Task 4 `blur 뒤에 온 pointerup은 두 번째 release를 만들지 않는다`.
5. **알 수 없는 `data-action` 값** (마크업 오타): 그 버튼을 무시하고 앱이 죽지 않아야 한다 → Task 4 `parseAction`.

```ts
import { BOARD_WIDTH, VISIBLE_HEIGHT } from '../core/constants';

/** style.css의 @media (max-width: 700px)와 맞춘다 */
export const MOBILE_MAX_WIDTH = 700;
export const MIN_CELL = 12;
/** .board-wrap의 테두리 두께 (style.css) */
export const BOARD_BORDER_PX = 2;
/** style.css의 같은 미디어 쿼리와 문자열을 맞춘다 */
export const TOUCH_QUERY = '(pointer: coarse)';
export const LANDSCAPE_QUERY =
  '(pointer: coarse) and (orientation: landscape) and (max-height: 500px)';

export function isMobileWidth(width: number): boolean {
  return width <= MOBILE_MAX_WIDTH;
}

export function desktopCell(windowHeight: number): number {
  return Math.max(MIN_CELL, Math.floor((windowHeight * 0.85) / VISIBLE_HEIGHT));
}

/** 보드가 들어갈 빈칸(#board-slot)의 실제 크기로 칸 크기를 정한다 */
export function slotCell(slotWidth: number, slotHeight: number): number {
  const border = 2 * BOARD_BORDER_PX;
  const fit = Math.min((slotWidth - border) / BOARD_WIDTH, (slotHeight - border) / VISIBLE_HEIGHT);
  return Math.max(MIN_CELL, Math.floor(fit));
}

export function miniCell(cell: number, mobile: boolean): number {
  return Math.floor(cell * (mobile ? 0.5 : 0.7));
}
```

```ts
import type { Action, InputEvent } from '../core/game';

export interface EventSource {
  /** 쌓인 입력 이벤트를 꺼내고 비운다 */
  drain(): InputEvent[];
}

export interface EventQueue extends EventSource {
  push(...events: InputEvent[]): void;
}

export function createEventQueue(): EventQueue {
  const queue: InputEvent[] = [];
  return {
    push: (...events) => {
      queue.push(...events);
    },
    drain: () => queue.splice(0),
  };
}

/** 입력원 순서대로 이어 붙인다. 한 틱 안의 순서라 게임에는 영향이 없다. */
export function mergeSources(...sources: EventSource[]): EventSource {
  return { drain: () => sources.flatMap((s) => s.drain()) };
}

export function tap(action: Action): InputEvent[] {
  return [
    { type: 'press', action },
    { type: 'release', action },
  ];
}
```

```ts
import { describe, expect, it } from 'vitest';
import type { Action, InputEvent } from '../core/game';
import { createGestureRecognizer } from './gestures';

const press = (action: Action): InputEvent => ({ type: 'press', action });
const release = (action: Action): InputEvent => ({ type: 'release', action });
const tapped = (action: Action): InputEvent[] => [press(action), release(action)];

const recognizer = (cell = 30) => createGestureRecognizer(() => cell);

describe('탭', () => {
  it('10px 미만으로 움직이고 250ms 안에 떼면 시계 방향 회전', () => {
    const g = recognizer();
    g.down(1, 100, 100, 0);
    g.up(1, 103, 104, 100);
    expect(g.drain()).toEqual(tapped('rotateCW'));
  });

  it('250ms를 넘기면 회전하지 않는다', () => {
    const g = recognizer();
    g.down(1, 100, 100, 0);
    g.up(1, 100, 100, 300);
    expect(g.drain()).toEqual([]);
  });

  it('10px 이상 움직이면 탭이 아니다', () => {
    const g = recognizer();
    g.down(1, 100, 100, 0);
    g.move(1, 112, 100, 50);
    g.up(1, 112, 100, 100);
    expect(g.drain()).toEqual([]);
  });
});

describe('가로 드래그', () => {
  it('손가락 위치를 칸 폭으로 나눈 몫만큼 따라가고, 되돌아오면 반대로 움직인다', () => {
    const g = recognizer(30);
    g.down(1, 0, 0, 0);
    g.move(1, 95, 0, 100);
    expect(g.drain()).toEqual([...tapped('right'), ...tapped('right'), ...tapped('right')]);
    g.move(1, 35, 0, 200);
    expect(g.drain()).toEqual([...tapped('left'), ...tapped('left')]);
    g.up(1, 35, 0, 300);
    expect(g.drain()).toEqual([]);
  });

  it('가로 모드로 정해진 뒤에는 아래로 흔들어도 소프트드롭이 나오지 않는다', () => {
    const g = recognizer(30);
    g.down(1, 0, 0, 0);
    g.move(1, 40, 5, 50);
    g.move(1, 45, 80, 100);
    g.tick(500);
    g.up(1, 45, 80, 600);
    expect(g.drain()).toEqual(tapped('right'));
  });

  it('cellPx가 0이면 가로 드래그를 무시한다', () => {
    const g = recognizer(0);
    g.down(1, 0, 0, 0);
    g.move(1, 300, 0, 50);
    g.up(1, 300, 0, 100);
    expect(g.drain()).toEqual([]);
  });
});

describe('세로 드래그', () => {
  it('아래로 천천히 끌면 방향이 정해지고 120ms 뒤 소프트드롭, 떼면 해제', () => {
    const g = recognizer();
    g.down(1, 0, 0, 0);
    g.move(1, 0, 15, 20);
    g.tick(100);
    expect(g.drain()).toEqual([]);
    g.tick(140);
    expect(g.drain()).toEqual([press('softDrop')]);
    g.move(1, 0, 60, 400);
    g.up(1, 0, 62, 1000);
    expect(g.drain()).toEqual([release('softDrop')]);
  });

  it('아래로 빠르게 튕기면 하드드롭만 나온다', () => {
    const g = recognizer();
    g.down(1, 0, 0, 0);
    g.move(1, 0, 20, 16);
    g.move(1, 0, 60, 40);
    g.up(1, 0, 100, 60);
    expect(g.drain()).toEqual(tapped('hardDrop'));
  });

  it('오래 끌다가 마지막에 빠르게 튕겨도 하드드롭', () => {
    const g = recognizer();
    g.down(1, 0, 0, 0);
    g.move(1, 0, 15, 20);
    g.tick(200);
    g.move(1, 0, 50, 500);
    g.move(1, 0, 55, 900);
    g.up(1, 0, 160, 1000);
    expect(g.drain()).toEqual([press('softDrop'), release('softDrop'), ...tapped('hardDrop')]);
  });

  it('위로 튕기면 홀드', () => {
    const g = recognizer();
    g.down(1, 0, 200, 0);
    g.move(1, 0, 185, 10);
    g.up(1, 0, 140, 60);
    expect(g.drain()).toEqual(tapped('hold'));

  it('위로 천천히 올렸다 떼면 아무것도 보내지 않는다', () => {
    const g = recognizer();

    g.move(1, 0, 185, 10);
    g.move(1, 0, 150, 400);
    g.up(1, 0, 150, 500);
    expect(g.drain()).toEqual([]);

describe('여러 포인터와 취소', () => {
  it('추적 중 들어온 두 번째 포인터는 무시한다', () => {
    const g = recognizer();
    g.down(1, 0, 0, 0);
    g.down(2, 50, 50, 10);
    g.up(2, 50, 50, 20);
    expect(g.drain()).toEqual([]);
    g.up(1, 0, 0, 100);
    expect(g.drain()).toEqual(tapped('rotateCW'));
  });

  it('시작하지 않은 포인터의 move/up은 무시한다', () => {
    const g = recognizer();
    g.move(5, 10, 10, 0);
    g.up(5, 10, 10, 50);
```

```ts
import type { InputEvent } from '../core/game';
import { createEventQueue, tap } from './input-hub';

export const TAP_MAX_MOVE_PX = 10;
export const TAP_MAX_MS = 250;
export const SOFT_DROP_DELAY_MS = 120;
/** px/ms */
export const HARD_DROP_MIN_SPEED = 1.0;
export const HOLD_MIN_DISTANCE_PX = 40;
/** px/ms */
export const HOLD_MIN_SPEED = 0.5;
export const VELOCITY_WINDOW_MS = 80;

interface Sample {
  readonly x: number;
  readonly y: number;
  readonly t: number;
}

interface Track {
  readonly id: number;
  readonly start: Sample;
  axis: 'none' | 'horizontal' | 'vertical';
  /** 방향이 정해진 시각 */
  axisT: number;
  /** 가로로 이미 보낸 칸 수 (오른쪽이 +) */
  steps: number;
  softDrop: boolean;
  /** samples[0]은 속도 계산 기준 샘플 */
  samples: Sample[];
}

export interface GestureRecognizer {
  down(id: number, x: number, y: number, t: number): void;
  move(id: number, x: number, y: number, t: number): void;
  up(id: number, x: number, y: number, t: number): void;
  cancel(id: number): void;
  cancelAll(): void;
  /** 손가락이 멈춰 있어도 소프트드롭 지연을 판정하도록 틱마다 호출한다 */
  tick(t: number): void;
  drain(): InputEvent[];
}

export function createGestureRecognizer(cellPx: () => number): GestureRecognizer {
  const out = createEventQueue();
  let track: Track | null = null;

  const last = (tr: Track) => tr.samples[tr.samples.length - 1];

  function addSample(tr: Track, s: Sample) {
    tr.samples.push(s);
    // 창 시작 이전의 샘플 중 가장 늦은 것 하나만 기준으로 남긴다
    while (tr.samples.length > 2 && tr.samples[1].t <= s.t - VELOCITY_WINDOW_MS) {
      tr.samples.shift();
    }
  }

  function velocityY(tr: Track): number {
    const first = tr.samples[0];
    const end = last(tr);
    const dt = end.t - first.t;
    return dt > 0 ? (end.y - first.y) / dt : 0;
  }

  function decideAxis(tr: Track, s: Sample) {
    if (tr.axis !== 'none') return;
    const dx = s.x - tr.start.x;
    const dy = s.y - tr.start.y;
    if (Math.hypot(dx, dy) < TAP_MAX_MOVE_PX) return;
    tr.axis = Math.abs(dx) >= Math.abs(dy) ? 'horizontal' : 'vertical';
    tr.axisT = s.t;
  }

  function followHorizontal(tr: Track, s: Sample) {
    if (tr.axis !== 'horizontal') return;
    const cell = cellPx();
    if (cell <= 0) return;
    const target = Math.trunc((s.x - tr.start.x) / cell);
    while (tr.steps < target) {
      out.push(...tap('right'));
      tr.steps++;
    }
    while (tr.steps > target) {
      out.push(...tap('left'));
      tr.steps--;
    }
  }

  function checkSoftDrop(tr: Track, t: number) {
    if (tr.axis !== 'vertical' || tr.softDrop) return;
    if (last(tr).y <= tr.start.y) return;
    if (t - tr.axisT < SOFT_DROP_DELAY_MS) return;
    tr.softDrop = true;
    out.push({ type: 'press', action: 'softDrop' });
  }

  function releaseSoftDrop(tr: Track) {
    if (!tr.softDrop) return;
    tr.softDrop = false;
    out.push({ type: 'release', action: 'softDrop' });
  }

  function update(tr: Track, x: number, y: number, t: number, allowSoftDrop: boolean) {
    const s = { x, y, t };
    addSample(tr, s);
    decideAxis(tr, s);
    followHorizontal(tr, s);
    if (allowSoftDrop) checkSoftDrop(tr, t);
  }

  const tracking = (id: number): Track | null => (track && track.id === id ? track : null);

  return {
    down(id, x, y, t) {
      if (track) return;
      const start = { x, y, t };
      track = { id, start, axis: 'none', axisT: t, steps: 0, softDrop: false, samples: [start] };
    },
    move(id, x, y, t) {
      const tr = tracking(id);
      if (tr) update(tr, x, y, t, true);
    },
    up(id, x, y, t) {
      const tr = tracking(id);
      if (!tr) return;
      // 떼는 순간에는 소프트드롭을 새로 시작하지 않는다
      update(tr, x, y, t, false);
      if (tr.axis === 'none') {
        if (t - tr.start.t <= TAP_MAX_MS) out.push(...tap('rotateCW'));
      } else if (tr.axis === 'vertical') {
        const v = velocityY(tr);
        if (v >= HARD_DROP_MIN_SPEED) {
          releaseSoftDrop(tr);
          out.push(...tap('hardDrop'));
        } else if (tr.start.y - y >= HOLD_MIN_DISTANCE_PX && -v >= HOLD_MIN_SPEED) {
          out.push(...tap('hold'));
        }
      }
      releaseSoftDrop(tr);
      track = null;
    },
    cancel(id) {
      const tr = tracking(id);
      if (!tr) return;
      releaseSoftDrop(tr);
      track = null;
    },
    cancelAll() {
      if (!track) return;
      releaseSoftDrop(track);
      track = null;
    },
    tick(t) {
      if (track) checkSoftDrop(track, t);
    },
    drain: () => out.drain(),
  };
}
```

```ts
import type { Action, InputEvent } from '../core/game';
import { createGestureRecognizer } from './gestures';
import { createEventQueue } from './input-hub';

const ACTIONS: readonly Action[] = [
  'left',
  'right',
  'softDrop',
  'hardDrop',
  'rotateCW',
  'rotateCCW',
  'hold',
  'pause',
  'start',
];

/** 마크업의 data-action 값을 검증한다. 모르는 값이면 undefined. */
export function parseAction(value: string | undefined): Action | undefined {
  return ACTIONS.find((a) => a === value);
}

interface PointerLike extends Event {
  readonly pointerId: number;
  readonly clientX: number;
  readonly clientY: number;
  readonly pointerType: string;
}

export interface ButtonBinding {
  readonly el: EventTarget;
  readonly action: Action;
}

export interface TouchOptions {
  win: EventTarget;
  doc: EventTarget & { readonly visibilityState: string };
  board: EventTarget & { setPointerCapture?(pointerId: number): void };
  buttons: readonly ButtonBinding[];
  /** 가로 드래그 한 칸의 CSS px */
  cellPx: () => number;
  /** 게임 루프와 같은 시계 (performance.now) */
  now: () => number;
}

export interface TouchInput {
  drain(): InputEvent[];
  tick(): void;
  releaseAll(): void;
  dispose(): void;
}

const isTouchPointer = (p: PointerLike) => p.pointerType === 'touch' || p.pointerType === 'pen';

export function createTouch(opts: TouchOptions): TouchInput {
  const queue = createEventQueue();
  const gestures = createGestureRecognizer(opts.cellPx);
  /** 버튼 → 누르고 있는 포인터 id */
  const held = new Map<ButtonBinding, number>();
  const cleanups: (() => void)[] = [];

  const listen = (target: EventTarget, type: string, handler: (e: Event) => void) => {
    target.addEventListener(type, handler);
    cleanups.push(() => target.removeEventListener(type, handler));
  };

  // 보드 제스처: 터치와 펜만 처리한다
  listen(opts.board, 'pointerdown', (e) => {
    const p = e as PointerLike;
    if (!isTouchPointer(p)) return;
    e.preventDefault();
    opts.board.setPointerCapture?.(p.pointerId);
    gestures.down(p.pointerId, p.clientX, p.clientY, opts.now());
  });
  listen(opts.board, 'pointermove', (e) => {
    const p = e as PointerLike;
    if (isTouchPointer(p)) gestures.move(p.pointerId, p.clientX, p.clientY, opts.now());
  });
  listen(opts.board, 'pointerup', (e) => {
    const p = e as PointerLike;
    if (isTouchPointer(p)) gestures.up(p.pointerId, p.clientX, p.clientY, opts.now());
  });
  listen(opts.board, 'pointercancel', (e) => {
    gestures.cancel((e as PointerLike).pointerId);
  });

  // 화면 버튼: 마우스도 허용한다
  for (const binding of opts.buttons) {
    listen(binding.el, 'pointerdown', (e) => {
      e.preventDefault();
      if (held.has(binding)) return;
      held.set(binding, (e as PointerLike).pointerId);
      queue.push({ type: 'press', action: binding.action });
    });
    const end = (e: Event) => {
      if (held.get(binding) !== (e as PointerLike).pointerId) return;
      held.delete(binding);
      queue.push({ type: 'release', action: binding.action });
    };
    listen(binding.el, 'pointerup', end);
    listen(binding.el, 'pointercancel', end);
    listen(binding.el, 'pointerleave', end);
  }

  const releaseAll = () => {
    for (const binding of held.keys()) queue.push({ type: 'release', action: binding.action });
    held.clear();
    gestures.cancelAll();
  };

  listen(opts.win, 'blur', releaseAll);
  listen(opts.doc, 'visibilitychange', () => {
    if (opts.doc.visibilityState === 'hidden') releaseAll();
  });

  return {
    drain: () => [...queue.drain(), ...gestures.drain()],
    tick: () => gestures.tick(opts.now()),
    releaseAll,
    dispose: () => {
      for (const cleanup of cleanups.splice(0)) cleanup();
    },
  };
}
```

```ts
export interface Renderer {
  resize(): void;
  draw(state: GameState): void;
  /** 현재 보드 칸 크기 (CSS px). 가로 드래그 한 칸의 기준 */
  cellPx(): number;
}

export function createRenderer(els: {
  board: HTMLCanvasElement;
  hold: HTMLCanvasElement;
  next: HTMLCanvasElement;
  /** 보드가 들어갈 빈칸. 모바일에서는 이 크기를 재서 칸 크기를 정한다 */
  slot: HTMLElement;
}): Renderer {
  const layout = () => {
    const mobile = isMobileWidth(window.innerWidth);
    const cell = mobile
      ? slotCell(els.slot.clientWidth, els.slot.clientHeight)
      : desktopCell(window.innerHeight);
    const mini = miniCell(cell, mobile);
    return {
      cell,
      mini,
      board: setupCanvas(els.board, BOARD_WIDTH * cell, VISIBLE_HEIGHT * cell),
      hold: setupCanvas(els.hold, MINI_COLS * mini, MINI_ROWS * mini),
      next: setupCanvas(els.next, MINI_COLS * mini, MINI_ROWS * mini * NEXT_PREVIEW_COUNT),
    };
  };
  let view = layout();

  return {
    resize: () => {
      view = layout();
    },
    draw: (state) => {
      drawBoard(view.board, state, view.cell);
      clear(view.hold);
      drawMini(view.hold, state.hold, view.mini, 0, state.canHold ? undefined : DISABLED);
      clear(view.next);
      nextPreview(state).forEach((type, i) => {
        drawMini(view.next, type, view.mini, i * MINI_ROWS * view.mini);
      });
    },
    cellPx: () => view.cell,
  };
}
```

```ts
import type { GameState, Phase } from '../core/state';

export interface HudElements {
  overlay: HTMLElement;
  score: HTMLElement;
  level: HTMLElement;
  lines: HTMLElement;
}

type Messages = Record<Exclude<Phase, 'playing'>, (s: GameState) => string[]>;

const KEYBOARD_MESSAGES: Messages = {
  ready: () => [
    'TETRIS',
    'Enter 키로 시작',
    '← → 이동 · ↓ 소프트드롭 · Space 하드드롭',
    '↑ / X 회전 · Z 반대 회전 · C 홀드 · Esc / P 일시정지',
  ],
  paused: () => ['일시정지', 'Esc 또는 P 키로 계속'],
  gameover: (s) => ['게임 오버', `점수 ${s.score.toLocaleString()}`, 'Enter 키로 다시 시작'],
};

const TOUCH_MESSAGES: Messages = {
  ready: () => [
    'TETRIS',
    '화면을 탭해서 시작',
    '탭 회전 · 좌우로 끌어 이동 · 아래로 끌어 소프트드롭',
    '아래로 튕겨 하드드롭 · 위로 튕겨 홀드',
  ],
  paused: () => ['일시정지', '탭해서 계속'],
  gameover: (s) => ['게임 오버', `점수 ${s.score.toLocaleString()}`, '탭해서 다시 시작'],
};

export function createHud(
  els: HudElements,
  options: { touch: boolean },
): { update(state: GameState): void } {
  const messages = options.touch ? TOUCH_MESSAGES : KEYBOARD_MESSAGES;
  let lastKey = '';
  return {
    update(state) {
      const key = `${state.phase}|${state.score}|${state.level}|${state.lines}`;
      if (key === lastKey) return;
      lastKey = key;
      els.score.textContent = state.score.toLocaleString();
      els.level.textContent = String(state.level);
      els.lines.textContent = String(state.lines);
      if (state.phase === 'playing') {
        els.overlay.hidden = true;
        return;
      }
      els.overlay.hidden = false;
      els.overlay.replaceChildren(
        ...messages[state.phase](state).map((text, i) => {
          const el = document.createElement(i === 0 ? 'h1' : 'p');
          el.textContent = text;
          return el;
        }),
      );
    },
  };
}
```

```ts
import './style.css';
import { TICK_MS } from './core/constants';
import { step } from './core/game';
import { createGame } from './core/state';
import { createEventQueue, mergeSources, tap } from './platform/input-hub';
import { createKeyboard } from './platform/keyboard';
import { startLoop } from './platform/loop';
import { type ButtonBinding, createTouch, parseAction } from './platform/touch';
import { createRenderer } from './render/canvas';
import { LANDSCAPE_QUERY, TOUCH_QUERY } from './render/layout';
import { createHud } from './render/overlay';

function byId<T extends HTMLElement>(id: string): T {
  const el = document.getElementById(id);
  if (!el) throw new Error(`#${id} 요소가 없습니다`);
  return el as T;
}

let state = createGame(Date.now() >>> 0);

const renderer = createRenderer({
  board: byId<HTMLCanvasElement>('board'),
  hold: byId<HTMLCanvasElement>('hold'),
  next: byId<HTMLCanvasElement>('next'),
  slot: byId('board-slot'),
});
const hud = createHud(
  { overlay: byId('overlay'), score: byId('score'), level: byId('level'), lines: byId('lines') },
  { touch: window.matchMedia(TOUCH_QUERY).matches },
);

const buttons: ButtonBinding[] = [];
for (const el of document.querySelectorAll<HTMLElement>('[data-action]')) {
  const action = parseAction(el.dataset.action);
  if (action) buttons.push({ el, action });
}

const keyboard = createKeyboard(window, document);
const touch = createTouch({
  win: window,
  doc: document,
  board: byId('board'),
  buttons,
  cellPx: () => renderer.cellPx(),
  now: () => performance.now(),
});
/** 오버레이 탭, 가로 방향 전환처럼 main이 직접 만드는 입력 */
const system = createEventQueue();
const input = mergeSources(keyboard, touch, system);

byId('overlay').addEventListener('click', () => {
  system.push(...tap(state.phase === 'paused' ? 'pause' : 'start'));
});

const landscape = window.matchMedia(LANDSCAPE_QUERY);
landscape.addEventListener('change', () => {
  if (landscape.matches) {
    touch.releaseAll();
    system.push({ type: 'focusLost' });
  }
  renderer.resize();
});
window.addEventListener('resize', () => renderer.resize());

startLoop(
  () => {
    touch.tick();
    state = step(state, input.drain(), TICK_MS);
  },
  () => {
    renderer.draw(state);
    hud.update(state);
  },
);
```
