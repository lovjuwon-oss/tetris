# 테트리스 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 테트리스 가이드라인을 따르는 싱글플레이 웹 브라우저 테트리스를 만든다.

**Architecture:** 게임 규칙은 DOM에 의존하지 않는 순수 TypeScript 모듈(`src/core`)로 만들고, 불변 상태를 받아 새 상태를 돌려주는 `step(state, events, dtMs)` 함수 하나로 진행한다. 브라우저 입력과 게임 루프는 `src/platform`, 그리기는 `src/render`가 맡는다. `core`는 시간과 입력을 인자로만 받으므로 같은 시드와 같은 입력이면 항상 같은 결과가 나온다.

**Tech Stack:** Vite, TypeScript(strict), Canvas 2D, Vitest(+ @vitest/coverage-v8), ESLint(typescript-eslint), Prettier. 실행 환경은 Windows + Git Bash, Node 24.

**Spec:** `docs/superpowers/specs/2026-09-28-tetris-design.md`

**설계 문서와의 차이:** 설계 문서의 `core/game.ts` 하나를 역할별로 세 파일로 나눈다. `state.ts`(상태 타입과 생성), `actions.ts`(블록 조작), `game.ts`(`step`과 입력 처리). 동작은 같다.

## Global Constraints

- 보드 10×40, 보이는 영역은 아래쪽 20행. y는 위에서 아래로 증가하며 보이는 영역은 y=20~39.
- 생성 위치: 바운딩 박스 x=3, y=18 (21~22행). 생성 직후 가능하면 1칸 낙하.
- DAS 167ms, ARR 33ms, 소프트드롭 중력 20배, 락 딜레이 500ms, 락 초기화 최대 15회.
- 중력: 한 줄 낙하 시간(초) = (0.8 − (레벨−1) × 0.007)^(레벨−1). 10줄마다 레벨업, 최대 15레벨.
- 점수: 싱글 100, 더블 300, 트리플 500, 테트리스 800 (× 삭제 전 레벨). 소프트드롭 칸당 1, 하드드롭 칸당 2.
- 고정 타임스텝 1/60초, 한 프레임 반영 시간 상한 100ms.
- 키 판별은 `event.code`로 한다. Ctrl, Shift는 쓰지 않는다. `event.repeat`는 무시한다.
- 블록 색: I `#31c7ef`, O `#f7d308`, T `#ad4d9c`, S `#42b642`, Z `#ef2029`, J `#5a65ad`, L `#ef7921`.
- `npm run check`(타입 검사 + 린트 + 포맷 검사 + 테스트와 커버리지)가 통과해야 작업 완료다.
- `src/core` 라인 커버리지 90% 이상.

```ts
import { SPAWN_X, SPAWN_Y } from './constants';

export type PieceType = 'I' | 'O' | 'T' | 'S' | 'Z' | 'J' | 'L';
export const PIECE_TYPES: readonly PieceType[] = ['I', 'O', 'T', 'S', 'Z', 'J', 'L'];

/** 0=생성 상태, 1=R(시계 90°), 2=180°, 3=L(반시계 90°) */
export type Rotation = 0 | 1 | 2 | 3;

export interface Point {
  readonly x: number;
  readonly y: number;
}

export interface ActivePiece {
  readonly type: PieceType;
  readonly rotation: Rotation;
  /** 바운딩 박스 왼쪽 위 */
  readonly x: number;
  readonly y: number;
}

const p = (x: number, y: number): Point => ({ x, y });

/** SRS 생성 상태 모양과 바운딩 박스 크기 */
const SPAWN_SHAPES: Record<PieceType, { size: number; cells: readonly Point[] }> = {
  I: { size: 4, cells: [p(0, 1), p(1, 1), p(2, 1), p(3, 1)] },
  O: { size: 4, cells: [p(1, 0), p(2, 0), p(1, 1), p(2, 1)] },
  T: { size: 3, cells: [p(1, 0), p(0, 1), p(1, 1), p(2, 1)] },
  S: { size: 3, cells: [p(1, 0), p(2, 0), p(0, 1), p(1, 1)] },
  Z: { size: 3, cells: [p(0, 0), p(1, 0), p(1, 1), p(2, 1)] },
  J: { size: 3, cells: [p(0, 0), p(0, 1), p(1, 1), p(2, 1)] },
  L: { size: 3, cells: [p(2, 0), p(0, 1), p(1, 1), p(2, 1)] },
};

/** 바운딩 박스 중심 기준 시계 방향 90° 회전 (y가 아래로 증가하는 좌표계) */
function rotateCW(cells: readonly Point[], size: number): Point[] {
  return cells.map((c) => p(size - 1 - c.y, c.x));
}

function buildStates(type: PieceType): readonly (readonly Point[])[] {
  const { size, cells } = SPAWN_SHAPES[type];
  if (type === 'O') return [cells, cells, cells, cells];
  const states: (readonly Point[])[] = [cells];
  for (let i = 1; i < 4; i++) states.push(rotateCW(states[i - 1], size));
  return states;
}

export const SHAPES = Object.fromEntries(PIECE_TYPES.map((t) => [t, buildStates(t)])) as Record<
  PieceType,
  readonly (readonly Point[])[]
>;

export function pieceCells(piece: ActivePiece): Point[] {
  return SHAPES[piece.type][piece.rotation].map((c) => p(c.x + piece.x, c.y + piece.y));
}

export function spawnPiece(type: PieceType): ActivePiece {
  return { type, rotation: 0, x: SPAWN_X, y: SPAWN_Y };
}
```

```ts
import { type Cell, type Grid, createGrid } from './board';
import { BOARD_HEIGHT } from './constants';
import type { PieceType, Point } from './pieces';

/** rows는 보드 맨 아래 행들. '.'은 빈칸, 그 외 문자는 블록 타입. */
export function gridFromRows(rows: readonly string[]): Grid {
  const grid = createGrid().map((row) => [...row]);
  const offset = BOARD_HEIGHT - rows.length;
  rows.forEach((row, i) => {
    [...row].forEach((ch, x) => {
      if (ch !== '.') grid[offset + i][x] = ch as PieceType;
    });
  });
  return grid;
}

/** 보드 맨 아래 count행을 문자열로 */
export function rowsOf(grid: Grid, count: number): string[] {
  return grid.slice(BOARD_HEIGHT - count).map((row) => row.map((c) => c ?? '.').join(''));
}

export function setCells(grid: Grid, points: readonly Point[], cell: Cell = 'Z'): Grid {
  const next = grid.map((row) => [...row]);
  for (const { x, y } of points) next[y][x] = cell;
  return next;
}

export function fullGrid(): Grid {
  return createGrid().map((row) => row.map((): Cell => 'Z'));
}
```

```ts
import { BOARD_HEIGHT, BOARD_WIDTH } from './constants';
import { type ActivePiece, type PieceType, pieceCells } from './pieces';

export type Cell = PieceType | null;
/** grid[y][x]. y=0이 맨 위 */
export type Grid = readonly (readonly Cell[])[];

function emptyRow(): Cell[] {
  return Array<Cell>(BOARD_WIDTH).fill(null);
}

export function createGrid(): Grid {
  return Array.from({ length: BOARD_HEIGHT }, emptyRow);
}

export function collides(grid: Grid, piece: ActivePiece): boolean {
  return pieceCells(piece).some(
    ({ x, y }) =>
      x < 0 || x >= BOARD_WIDTH || y < 0 || y >= BOARD_HEIGHT || grid[y][x] !== null,
  );
}

export function lockPiece(grid: Grid, piece: ActivePiece): Grid {
  const next = grid.map((row) => [...row]);
  for (const { x, y } of pieceCells(piece)) next[y][x] = piece.type;
  return next;
}

export function clearLines(grid: Grid): { grid: Grid; cleared: number } {
  const remaining = grid.filter((row) => row.some((c) => c === null));
  const cleared = grid.length - remaining.length;
  return { grid: [...Array.from({ length: cleared }, emptyRow), ...remaining], cleared };
}

export function dropDistance(grid: Grid, piece: ActivePiece): number {
  let distance = 0;
  while (!collides(grid, { ...piece, y: piece.y + distance + 1 })) distance++;
  return distance;
}
```

```ts
import { type Grid, collides } from './board';
import type { ActivePiece, PieceType, Point, Rotation } from './pieces';

export type RotateDirection = 1 | -1;

type KickTable = Record<string, readonly (readonly [number, number])[]>;

// SRS 위키 표기 그대로 적는다 (y축 위쪽이 +). kicksFor에서 y 부호를 뒤집는다.
// prettier-ignore
const JLSTZ_KICKS: KickTable = {
  '0>1': [[0, 0], [-1, 0], [-1, 1], [0, -2], [-1, -2]],
  '1>0': [[0, 0], [1, 0], [1, -1], [0, 2], [1, 2]],
  '1>2': [[0, 0], [1, 0], [1, -1], [0, 2], [1, 2]],
  '2>1': [[0, 0], [-1, 0], [-1, 1], [0, -2], [-1, -2]],
  '2>3': [[0, 0], [1, 0], [1, 1], [0, -2], [1, -2]],
  '3>2': [[0, 0], [-1, 0], [-1, -1], [0, 2], [-1, 2]],
  '3>0': [[0, 0], [-1, 0], [-1, -1], [0, 2], [-1, 2]],
  '0>3': [[0, 0], [1, 0], [1, 1], [0, -2], [1, -2]],
};

// prettier-ignore
const I_KICKS: KickTable = {
  '0>1': [[0, 0], [-2, 0], [1, 0], [-2, -1], [1, 2]],
  '1>0': [[0, 0], [2, 0], [-1, 0], [2, 1], [-1, -2]],
  '1>2': [[0, 0], [-1, 0], [2, 0], [-1, 2], [2, -1]],
  '2>1': [[0, 0], [1, 0], [-2, 0], [1, -2], [-2, 1]],
  '2>3': [[0, 0], [2, 0], [-1, 0], [2, 1], [-1, -2]],
  '3>2': [[0, 0], [-2, 0], [1, 0], [-2, -1], [1, 2]],
  '3>0': [[0, 0], [1, 0], [-2, 0], [1, -2], [-2, 1]],
  '0>3': [[0, 0], [-1, 0], [2, 0], [-1, 2], [2, -1]],
};

export function kicksFor(type: PieceType, from: Rotation, to: Rotation): readonly Point[] {
  const table = type === 'I' ? I_KICKS : JLSTZ_KICKS;
  // 0 - y는 y가 0일 때 -0 대신 0을 만든다
  return table[`${from}>${to}`].map(([x, y]) => ({ x, y: 0 - y }));
}

export function tryRotate(grid: Grid, piece: ActivePiece, dir: RotateDirection): ActivePiece | null {
  if (piece.type === 'O') return null;
  const to = ((piece.rotation + dir + 4) % 4) as Rotation;
  for (const kick of kicksFor(piece.type, piece.rotation, to)) {
    const candidate = { ...piece, rotation: to, x: piece.x + kick.x, y: piece.y + kick.y };
    if (!collides(grid, candidate)) return candidate;
  }
  return null;
}
```

```ts
/** mulberry32. 상태를 인자로 받고 돌려주는 순수 함수라 게임 상태에 그대로 담을 수 있다. */
export function nextRandom(state: number): { value: number; state: number } {
  const next = (state + 0x6d2b79f5) >>> 0;
  let t = next;
  t = Math.imul(t ^ (t >>> 15), t | 1);
  t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
  return { value: ((t ^ (t >>> 14)) >>> 0) / 4294967296, state: next };
}
```

`src/core/randomizer.ts`:
```ts
import { NEXT_PREVIEW_COUNT } from './constants';
import { PIECE_TYPES, type PieceType } from './pieces';
import { nextRandom } from './rng';

export interface BagState {
  readonly queue: readonly PieceType[];
  readonly rngState: number;
}

function shuffledBag(rngState: number): { pieces: PieceType[]; rngState: number } {
  const pieces = [...PIECE_TYPES];
  let state = rngState;
  for (let i = pieces.length - 1; i > 0; i--) {
    const r = nextRandom(state);
    state = r.state;
    const j = Math.floor(r.value * (i + 1));
    [pieces[i], pieces[j]] = [pieces[j], pieces[i]];
  }
  return { pieces, rngState: state };
}

function refill(bag: BagState, minLength: number): BagState {
  let { queue, rngState } = bag;
  while (queue.length < minLength) {
    const shuffled = shuffledBag(rngState);
    queue = [...queue, ...shuffled.pieces];
    rngState = shuffled.rngState;
  }
  return { queue, rngState };
}

export function createBag(seed: number): BagState {
  return refill({ queue: [], rngState: seed >>> 0 }, NEXT_PREVIEW_COUNT + 1);
}

export function takeNext(bag: BagState): { piece: PieceType; bag: BagState } {
  const filled = refill(bag, NEXT_PREVIEW_COUNT + 1);
  const [piece, ...rest] = filled.queue;
  return { piece, bag: { queue: rest, rngState: filled.rngState } };
}
```

```ts
export const SOFT_DROP_POINTS_PER_CELL = 1;
export const HARD_DROP_POINTS_PER_CELL = 2;

const LINE_CLEAR_POINTS: readonly number[] = [0, 100, 300, 500, 800];

/** 블록 하나가 고정될 때 일어난 일. T-spin, 콤보 등은 여기에 필드로 추가한다. */

export function scoreForLock(event: LockEvent, level: number): number {
  return (LINE_CLEAR_POINTS[event.linesCleared] ?? 0) * level;

export function levelForLines(totalLines: number): number {
  return Math.min(MAX_LEVEL, 1 + Math.floor(totalLines / LINES_PER_LEVEL));
}

export function gravityMsPerRow(level: number): number {
  return Math.pow(0.8 - (level - 1) * 0.007, level - 1) * 1000;
}
```

```ts
function ticks(state: ShiftState, ...dts: number[]): { state: ShiftState; steps: number[] } {
```

```ts
import { ARR_MS, DAS_MS } from './constants';

export type Direction = -1 | 1;

export interface ShiftState {
  readonly left: boolean;
  readonly right: boolean;
  /** 현재 적용 중인 방향. 나중에 누른 쪽이 우선한다. */
  readonly dir: -1 | 0 | 1;
  /** 현재 방향을 누르고 있은 시간 */
  readonly heldMs: number;
}

export const INITIAL_SHIFT: ShiftState = { left: false, right: false, dir: 0, heldMs: 0 };

export function pressShift(s: ShiftState, d: Direction): ShiftState {
  return {
    left: d === -1 ? true : s.left,
    right: d === 1 ? true : s.right,
    dir: d,
    heldMs: 0,
  };
}

export function releaseShift(s: ShiftState, d: Direction): ShiftState {
  const left = d === -1 ? false : s.left;
  const right = d === 1 ? false : s.right;
  if (s.dir !== d) return { ...s, left, right };
  const dir = left ? -1 : right ? 1 : 0;
  return { left, right, dir, heldMs: 0 };
}

/** 누른 뒤 ms가 지났을 때까지 일어났어야 할 자동 반복 횟수 */
function repeatsAt(ms: number): number {
  return ms < DAS_MS ? 0 : Math.floor((ms - DAS_MS) / ARR_MS) + 1;
}

export function tickShift(s: ShiftState, dtMs: number): { state: ShiftState; steps: number } {
  if (s.dir === 0) return { state: s, steps: 0 };
  const heldMs = s.heldMs + dtMs;
  return { state: { ...s, heldMs }, steps: repeatsAt(heldMs) - repeatsAt(s.heldMs) };
}
```

```ts
import { clearLines, collides, dropDistance, lockPiece } from './board';
import { MAX_LOCK_RESETS, VISIBLE_TOP } from './constants';
import { type ActivePiece, type PieceType, pieceCells, spawnPiece } from './pieces';
import { takeNext } from './randomizer';
import { HARD_DROP_POINTS_PER_CELL, levelForLines, scoreForLock } from './scoring';
import { type RotateDirection, tryRotate } from './srs';
import type { GameState } from './state';

/** type 블록을 생성 위치에 놓는다. 막혀 있으면 블록 아웃. */
function placeNew(state: GameState, type: PieceType): GameState {
  let piece = spawnPiece(type);
  if (collides(state.grid, piece)) return { ...state, active: null, phase: 'gameover' };
  const lowered = { ...piece, y: piece.y + 1 };
  if (!collides(state.grid, lowered)) piece = lowered;
  return {
    ...state,
    active: piece,
    gravityMs: 0,
    lockMs: 0,
    resetsLeft: MAX_LOCK_RESETS,
    lowestY: piece.y,
  };
}

export function spawnNext(state: GameState): GameState {
  const { piece, bag } = takeNext(state.bag);
  return placeNew({ ...state, bag, canHold: true }, piece);
}

export function isGrounded(state: GameState): boolean {
  const a = state.active;
  return a !== null && collides(state.grid, { ...a, y: a.y + 1 });
}

/** 이동에 성공한 블록을 반영하면서 락 초기화 규칙을 적용한다 */
function withPiece(state: GameState, piece: ActivePiece): GameState {
  let { lockMs, resetsLeft, lowestY } = state;
  if (isGrounded(state) && resetsLeft > 0) {
    lockMs = 0;
    resetsLeft -= 1;
  }
  if (piece.y > lowestY) {
    lowestY = piece.y;
    resetsLeft = MAX_LOCK_RESETS;
    lockMs = 0;
  }
  return { ...state, active: piece, lockMs, resetsLeft, lowestY };
}

export function moveHorizontal(state: GameState, dx: number): GameState {
  const a = state.active;
  if (!a) return state;
  const moved = { ...a, x: a.x + dx };
  return collides(state.grid, moved) ? state : withPiece(state, moved);
}

export function moveDown(state: GameState): GameState | null {
  const a = state.active;
  if (!a) return null;
  const moved = { ...a, y: a.y + 1 };
  return collides(state.grid, moved) ? null : withPiece(state, moved);
}

export function rotate(state: GameState, dir: RotateDirection): GameState {
  const a = state.active;
  if (!a) return state;
  const rotated = tryRotate(state.grid, a, dir);
  return rotated ? withPiece(state, rotated) : state;
}

export function lockActive(state: GameState): GameState {
  const a = state.active;
  if (!a) return state;
  const locked = lockPiece(state.grid, a);
  if (pieceCells(a).every((c) => c.y < VISIBLE_TOP)) {
    return { ...state, grid: locked, active: null, phase: 'gameover' };
  }
  const { grid, cleared } = clearLines(locked);
  const lines = state.lines + cleared;
  return spawnNext({
    ...state,
    grid,
    active: null,
    lines,
    level: levelForLines(lines),
    score: state.score + scoreForLock({ linesCleared: cleared }, state.level),
  });
}

export function hardDrop(state: GameState): GameState {
  const a = state.active;
  if (!a) return state;
  const distance = dropDistance(state.grid, a);
  return lockActive({
    ...state,
    active: { ...a, y: a.y + distance },
    score: state.score + distance * HARD_DROP_POINTS_PER_CELL,
  });
}

export function hold(state: GameState): GameState {
  const a = state.active;
  if (!a || !state.canHold) return state;
  if (state.hold === null) {
    const { piece, bag } = takeNext(state.bag);
    return placeNew({ ...state, hold: a.type, canHold: false, bag }, piece);
  }
  return placeNew({ ...state, hold: a.type, canHold: false }, state.hold);
}
```

```ts
import {
  hardDrop,
  hold,
  isGrounded,
  lockActive,
  moveDown,
  moveHorizontal,
  rotate,
  spawnNext,
} from './actions';
import { LOCK_DELAY_MS, SOFT_DROP_FACTOR } from './constants';
import { INITIAL_SHIFT, pressShift, releaseShift, tickShift } from './input';
import { SOFT_DROP_POINTS_PER_CELL, gravityMsPerRow } from './scoring';
import { type GameState, createGame } from './state';

export type Action =
  | 'left'
  | 'right'
  | 'softDrop'
  | 'hardDrop'
  | 'rotateCW'
  | 'rotateCCW'
  | 'hold'
  | 'pause'
  | 'start';

export type InputEvent =
  | { readonly type: 'press' | 'release'; readonly action: Action }
  | { readonly type: 'focusLost' };

function startOrRestart(s: GameState): GameState {
  if (s.phase === 'ready') return spawnNext({ ...s, phase: 'playing' });
  if (s.phase === 'gameover') return spawnNext({ ...createGame(s.bag.rngState), phase: 'playing' });
  return s;
}

function togglePause(s: GameState): GameState {
  if (s.phase === 'playing') return { ...s, phase: 'paused' };
  if (s.phase === 'paused') return { ...s, phase: 'playing' };
  return s;
}

function applyPress(s: GameState, action: Action): GameState {
  const playing = s.phase === 'playing';
  switch (action) {
    case 'start':
      return startOrRestart(s);
    case 'pause':
      return togglePause(s);
    case 'left':
    case 'right': {
      const d = action === 'left' ? -1 : 1;
      const next = { ...s, shift: pressShift(s.shift, d) };
      return playing ? moveHorizontal(next, d) : next;
    }
    case 'softDrop':
      return { ...s, softDrop: true };
    case 'hardDrop':
      return playing ? hardDrop(s) : s;
    case 'rotateCW':
      return playing ? rotate(s, 1) : s;
    case 'rotateCCW':
      return playing ? rotate(s, -1) : s;
    case 'hold':
      return playing ? hold(s) : s;
  }
}

function applyRelease(s: GameState, action: Action): GameState {
  switch (action) {
    case 'left':
      return { ...s, shift: releaseShift(s.shift, -1) };
    case 'right':
      return { ...s, shift: releaseShift(s.shift, 1) };
    case 'softDrop':
      return { ...s, softDrop: false };
    default:
      return s;
  }
}

function applyEvent(s: GameState, e: InputEvent): GameState {
  if (e.type === 'focusLost') {
    const phase = s.phase === 'playing' ? 'paused' : s.phase;
    return { ...s, phase, shift: INITIAL_SHIFT, softDrop: false };
  }
  return e.type === 'press' ? applyPress(s, e.action) : applyRelease(s, e.action);
}

function applyShiftRepeat(s: GameState, dtMs: number): GameState {
  const { state: shift, steps } = tickShift(s.shift, dtMs);
  let next: GameState = { ...s, shift };
  for (let i = 0; i < steps && shift.dir !== 0; i++) {
    const moved = moveHorizontal(next, shift.dir);
    if (moved === next) break;
    next = moved;
  }
  return next;
}

/** 여러 칸을 떨어져야 할 때도 한 칸씩 충돌을 검사한다 */
function applyGravity(s: GameState, dtMs: number): GameState {
  if (!s.active) return s;
  const interval = gravityMsPerRow(s.level) / (s.softDrop ? SOFT_DROP_FACTOR : 1);
  let gravityMs = s.gravityMs + dtMs;
  let next = s;
  while (gravityMs >= interval) {
    const moved = moveDown(next);
    if (!moved) {
      gravityMs = 0;
      break;
    }
    gravityMs -= interval;
    next = s.softDrop ? { ...moved, score: moved.score + SOFT_DROP_POINTS_PER_CELL } : moved;
  }
  return { ...next, gravityMs };
}

function applyLockDelay(s: GameState, dtMs: number): GameState {
  if (!isGrounded(s)) return { ...s, lockMs: 0 };
  if (s.resetsLeft === 0) return lockActive(s);
  const lockMs = s.lockMs + dtMs;
  return lockMs >= LOCK_DELAY_MS ? lockActive(s) : { ...s, lockMs };
}

export function step(state: GameState, events: readonly InputEvent[], dtMs: number): GameState {
  let s = state;
  for (const e of events) s = applyEvent(s, e);
  if (s.phase !== 'playing') return s;
  s = applyShiftRepeat(s, dtMs);
  s = applyGravity(s, dtMs);
  return applyLockDelay(s, dtMs);
}
```

```ts
import { MAX_FRAME_MS, TICK_MS } from '../core/constants';

/** 고정 타임스텝 누적기. 긴 공백(백그라운드 탭 복귀 등)은 MAX_FRAME_MS로 자른다. */
export function advance(accMs: number, elapsedMs: number): { ticks: number; accMs: number } {
  let acc = accMs + Math.min(elapsedMs, MAX_FRAME_MS);
  let ticks = 0;
  while (acc >= TICK_MS) {
    acc -= TICK_MS;
    ticks++;
  }
  return { ticks, accMs: acc };
}

export function startLoop(onTick: () => void, onRender: () => void): () => void {
  let acc = 0;
  let last = performance.now();
  let handle = 0;
  const frame = (now: number) => {
    const r = advance(acc, now - last);
    last = now;
    acc = r.accMs;
    for (let i = 0; i < r.ticks; i++) onTick();
    onRender();
    handle = requestAnimationFrame(frame);
  };
  handle = requestAnimationFrame(frame);
  return () => cancelAnimationFrame(handle);
}
```

```ts
import type { Action, InputEvent } from '../core/game';

/** event.code 기준이라 한글 입력 상태에서도 같은 키로 동작한다 */
const KEY_MAP = new Map<string, Action>([
  ['ArrowLeft', 'left'],
  ['ArrowRight', 'right'],
  ['ArrowDown', 'softDrop'],
  ['Space', 'hardDrop'],
  ['ArrowUp', 'rotateCW'],
  ['KeyX', 'rotateCW'],
  ['KeyZ', 'rotateCCW'],
  ['KeyC', 'hold'],
  ['Escape', 'pause'],
  ['KeyP', 'pause'],
  ['Enter', 'start'],
  ['NumpadEnter', 'start'],
]);

export function actionForCode(code: string): Action | undefined {
  return KEY_MAP.get(code);
}

interface KeyEventLike extends Event {
  readonly code: string;
  readonly repeat: boolean;
}

export interface Keyboard {
  /** 쌓인 입력 이벤트를 꺼내고 비운다 */
  drain(): InputEvent[];
  dispose(): void;
}

export function createKeyboard(
  win: EventTarget,
  doc: EventTarget & { readonly visibilityState: string },
): Keyboard {
  const queue: InputEvent[] = [];
  const held = new Set<string>();

  const onKeyDown = (e: Event) => {
    const { code, repeat } = e as KeyEventLike;
    const action = actionForCode(code);
    if (!action) return;
    e.preventDefault();
    if (repeat || held.has(code)) return;
    held.add(code);
    queue.push({ type: 'press', action });
  };

  const onKeyUp = (e: Event) => {
    const { code } = e as KeyEventLike;
    const action = actionForCode(code);
    if (!action || !held.delete(code)) return;
    queue.push({ type: 'release', action });
  };

  const onFocusLost = () => {
    for (const code of held) {
      const action = actionForCode(code);
      if (action) queue.push({ type: 'release', action });
    }
    held.clear();
    queue.push({ type: 'focusLost' });
  };

  const onVisibilityChange = () => {
    if (doc.visibilityState === 'hidden') onFocusLost();
  };

  win.addEventListener('keydown', onKeyDown);
  win.addEventListener('keyup', onKeyUp);
  win.addEventListener('blur', onFocusLost);
  doc.addEventListener('visibilitychange', onVisibilityChange);

  return {
    drain: () => queue.splice(0),
    dispose: () => {
      win.removeEventListener('keydown', onKeyDown);
      win.removeEventListener('keyup', onKeyUp);
      win.removeEventListener('blur', onFocusLost);
      doc.removeEventListener('visibilitychange', onVisibilityChange);
    },
  };
}
```

```ts
import { dropDistance } from '../core/board';
import {
  BOARD_HEIGHT,
  BOARD_WIDTH,
  NEXT_PREVIEW_COUNT,
  VISIBLE_HEIGHT,
  VISIBLE_TOP,
} from '../core/constants';
import { type PieceType, type Point, SHAPES, pieceCells } from '../core/pieces';
import { type GameState, nextPreview } from '../core/state';

export const PIECE_COLORS: Record<PieceType, string> = {
  I: '#31c7ef',
  O: '#f7d308',
  T: '#ad4d9c',
  S: '#42b642',
  Z: '#ef2029',
  J: '#5a65ad',
  L: '#ef7921',
};

const BACKGROUND = '#10131a';
const GRID_LINE = '#1c212c';
const DISABLED = '#4a4f5c';
const MIN_CELL = 12;
const MINI_SCALE = 0.7;
const MINI_COLS = 5;
const MINI_ROWS = 3;

function setupCanvas(canvas: HTMLCanvasElement, width: number, height: number) {
  const dpr = window.devicePixelRatio || 1;
  canvas.style.width = `${width}px`;
  canvas.style.height = `${height}px`;
  canvas.width = Math.round(width * dpr);
  canvas.height = Math.round(height * dpr);
  const ctx = canvas.getContext('2d');
  if (!ctx) throw new Error('Canvas 2D를 사용할 수 없습니다');
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  return ctx;
}

function clear(ctx: CanvasRenderingContext2D) {
  ctx.fillStyle = BACKGROUND;
  ctx.fillRect(0, 0, ctx.canvas.width, ctx.canvas.height);
}

function drawBlock(ctx: CanvasRenderingContext2D, px: number, py: number, size: number, color: string) {
  ctx.fillStyle = color;
  ctx.fillRect(px + 1, py + 1, size - 2, size - 2);
  ctx.fillStyle = 'rgba(255, 255, 255, 0.18)';
  ctx.fillRect(px + 1, py + 1, size - 2, Math.max(2, Math.floor(size * 0.15)));
}

function drawGhost(ctx: CanvasRenderingContext2D, px: number, py: number, size: number, color: string) {
  ctx.globalAlpha = 0.45;
  ctx.strokeStyle = color;
  ctx.lineWidth = 2;
  ctx.strokeRect(px + 2, py + 2, size - 4, size - 4);
  ctx.globalAlpha = 1;
}

const visible = (cells: readonly Point[]) => cells.filter((c) => c.y >= VISIBLE_TOP);

function drawBoard(ctx: CanvasRenderingContext2D, state: GameState, cell: number) {
  clear(ctx);
  ctx.strokeStyle = GRID_LINE;
  ctx.lineWidth = 1;
  ctx.beginPath();
  for (let x = 1; x < BOARD_WIDTH; x++) {
    ctx.moveTo(x * cell + 0.5, 0);
    ctx.lineTo(x * cell + 0.5, VISIBLE_HEIGHT * cell);
  }
  for (let y = 1; y < VISIBLE_HEIGHT; y++) {
    ctx.moveTo(0, y * cell + 0.5);
    ctx.lineTo(BOARD_WIDTH * cell, y * cell + 0.5);
  }
  ctx.stroke();

  for (let y = VISIBLE_TOP; y < BOARD_HEIGHT; y++) {
    for (let x = 0; x < BOARD_WIDTH; x++) {
      const c = state.grid[y][x];
      if (c) drawBlock(ctx, x * cell, (y - VISIBLE_TOP) * cell, cell, PIECE_COLORS[c]);
    }
  }

  const a = state.active;
  if (!a) return;
  const color = PIECE_COLORS[a.type];
  const ghost = { ...a, y: a.y + dropDistance(state.grid, a) };
  for (const c of visible(pieceCells(ghost))) {
    drawGhost(ctx, c.x * cell, (c.y - VISIBLE_TOP) * cell, cell, color);
  }
  for (const c of visible(pieceCells(a))) {
    drawBlock(ctx, c.x * cell, (c.y - VISIBLE_TOP) * cell, cell, color);
  }
}

/** MINI_COLS × MINI_ROWS 칸 슬롯의 가운데에 블록을 그린다 */
function drawMini(
  ctx: CanvasRenderingContext2D,
  type: PieceType | null,
  mini: number,
  offsetY: number,
  color?: string,
) {
  if (!type) return;
  const cells = SHAPES[type][0];
  const xs = cells.map((c) => c.x);
  const ys = cells.map((c) => c.y);
  const minX = Math.min(...xs);
  const minY = Math.min(...ys);
  const width = (Math.max(...xs) - minX + 1) * mini;
  const height = (Math.max(...ys) - minY + 1) * mini;
  const ox = (MINI_COLS * mini - width) / 2;
  const oy = offsetY + (MINI_ROWS * mini - height) / 2;
  for (const c of cells) {
    const px = Math.round(ox + (c.x - minX) * mini);
    const py = Math.round(oy + (c.y - minY) * mini);
    drawBlock(ctx, px, py, mini, color ?? PIECE_COLORS[type]);
  }
}

export interface Renderer {
  resize(): void;
  draw(state: GameState): void;
}

export function createRenderer(canvases: {
  board: HTMLCanvasElement;
  hold: HTMLCanvasElement;
  next: HTMLCanvasElement;
}): Renderer {
  const layout = () => {
    const cell = Math.max(MIN_CELL, Math.floor((window.innerHeight * 0.85) / VISIBLE_HEIGHT));
    const mini = Math.floor(cell * MINI_SCALE);
    return {
      cell,
      mini,
      board: setupCanvas(canvases.board, BOARD_WIDTH * cell, VISIBLE_HEIGHT * cell),
      hold: setupCanvas(canvases.hold, MINI_COLS * mini, MINI_ROWS * mini),
      next: setupCanvas(canvases.next, MINI_COLS * mini, MINI_ROWS * mini * NEXT_PREVIEW_COUNT),
    };
  };
  let view = layout();

  return {
    resize: () => {
      view = layout();
    },
    draw: (state) => {
      drawBoard(view.board, state, view.cell);
      clear(view.hold);
      drawMini(view.hold, state.hold, view.mini, 0, state.canHold ? undefined : DISABLED);
      clear(view.next);
      nextPreview(state).forEach((type, i) => {
        drawMini(view.next, type, view.mini, i * MINI_ROWS * view.mini);
      });
    },
  };
}
```

```ts
import type { GameState, Phase } from '../core/state';

export interface HudElements {
  overlay: HTMLElement;
  score: HTMLElement;
  level: HTMLElement;
  lines: HTMLElement;
}

const MESSAGES: Record<Exclude<Phase, 'playing'>, (s: GameState) => string[]> = {
  ready: () => [
    'TETRIS',
    'Enter 키로 시작',
    '← → 이동 · ↓ 소프트드롭 · Space 하드드롭',
    '↑ / X 회전 · Z 반대 회전 · C 홀드 · Esc / P 일시정지',
  ],
  paused: () => ['일시정지', 'Esc 또는 P 키로 계속'],
  gameover: (s) => ['게임 오버', `점수 ${s.score.toLocaleString()}`, 'Enter 키로 다시 시작'],
};

export function createHud(els: HudElements): { update(state: GameState): void } {
  let lastKey = '';
  return {
    update(state) {
      const key = `${state.phase}|${state.score}|${state.level}|${state.lines}`;
      if (key === lastKey) return;
      lastKey = key;
      els.score.textContent = state.score.toLocaleString();
      els.level.textContent = String(state.level);
      els.lines.textContent = String(state.lines);
      if (state.phase === 'playing') {
        els.overlay.hidden = true;
        return;
      }
      els.overlay.hidden = false;
      els.overlay.replaceChildren(
        ...MESSAGES[state.phase](state).map((text, i) => {
          const el = document.createElement(i === 0 ? 'h1' : 'p');
          el.textContent = text;
          return el;
        }),
      );
    },
  };
}
```

```ts
import './style.css';
import { TICK_MS } from './core/constants';
import { step } from './core/game';
import { createGame } from './core/state';
import { createKeyboard } from './platform/keyboard';
import { startLoop } from './platform/loop';
import { createRenderer } from './render/canvas';
import { createHud } from './render/overlay';

function byId<T extends HTMLElement>(id: string): T {
  const el = document.getElementById(id);
  if (!el) throw new Error(`#${id} 요소가 없습니다`);
  return el as T;
}

let state = createGame(Date.now() >>> 0);
const keyboard = createKeyboard(window, document);
const renderer = createRenderer({
  board: byId<HTMLCanvasElement>('board'),
  hold: byId<HTMLCanvasElement>('hold'),
  next: byId<HTMLCanvasElement>('next'),
});
const hud = createHud({
  overlay: byId('overlay'),
  score: byId('score'),
  level: byId('level'),
  lines: byId('lines'),
});

window.addEventListener('resize', () => renderer.resize());

startLoop(
  () => {
    state = step(state, keyboard.drain(), TICK_MS);
  },
  () => {
    renderer.draw(state);
    hud.update(state);
  },
);
```
